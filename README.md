## Project Description
This console-based Cybersecurity Awareness Chatbot is designed to educate South African users about online safety through interactive conversations. The chatbot covers essential topics including:

- Password security best practices
- Phishing email identification
- General cybersecurity awareness

Built in C# for the .NET platform, the application features:
- Voice greetings
- ASCII art interface
- Interactive scenarios
- Context-aware conversations

## Features

### Core Functionality
✅ Personalized greetings using user's name  
✅ Audio welcome message (WAV format)  
✅ ASCII art interface header  
✅ Interactive phishing scenario practice  
✅ Password strength guidance  

### Cybersecurity Education
🔒 Realistic South African phishing examples (FNB, Standard Bank)  
🔒 Password creation best practices  
🔒 Immediate feedback on security choices  

### Technical Features
💻 Console color formatting  
⌨️ Simulated typing effects  
🔄 Context-aware responses
